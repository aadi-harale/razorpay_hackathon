# ShadowFunnel product workflow

The UI is organized around one merchant operating loop rather than independent dashboard pages.

1. **Merchant Readiness** — open the workspace control in the sidebar to see tax, catalog, inventory, current evidence, Razorpay and agent API readiness.
2. **Live Buyer** — preflight any natural-language buyer request without reserving stock or moving money; use the flagship flow for the complete bound checkout.
3. **Shadow Funnel** — inspect contacted-agent drop-off after the observable query boundary and keep silent external-agent reasons UNKNOWN.
4. **Opportunities** — use paired/stateful replay to rank merchant changes by net incremental contribution.
5. **Audit** — search and filter the server authority ledger for evidence, policy, inventory and payment transitions.

The primary user journey is: **Setup → Preflight → Verify → Replan → Reserve → Pay → Learn → Audit**.
